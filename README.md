# Prisma & PostgreSQL Backend Server

A production-ready REST API built with Express.js, TypeScript, Prisma ORM, and PostgreSQL — developed as part of the SCIC/EJP-13 Backend Workshop.

## Tech Stack
- Express.js
- TypeScript
- PostgreSQL (via Supabase/NeonDB)
- Prisma ORM
- JWT Authentication
- bcrypt
